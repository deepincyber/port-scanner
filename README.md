# Python Port Scanner

A beginner-friendly Python tool that scans a target system for open TCP ports and helps identify potentially accessible network services.

## Project Goal

The goal of this project is to understand how TCP ports work and how port scanning can be used as part of network security assessment.

## Planned Features

- Scan a single target IP address
- Scan a range of ports
- Identify open ports
- Display basic service information
- Add configurable port ranges
- Improve scanning speed using Python
